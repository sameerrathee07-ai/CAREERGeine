# CareerGenie

An AI-powered Resume Analyzer and Smart Job Matching platform that helps students improve their resumes, prepare for interviews, and discover relevant career opportunities while enabling recruiters to efficiently find qualified candidates.

---

# Overview

CareerGenie is a full-stack web application that combines AI-powered resume analysis, ATS optimization, and intelligent job matching into a single platform.

Students receive personalized resume feedback, ATS compatibility scores, career recommendations, and job matches. Recruiters can post jobs, manage applications, review candidates, and streamline the hiring process through a modern dashboard.
